# Changelog — PBZFreeRevert（免费回退重置）

## v1.0.0
- 正式发布：基于 1.03 官方脚本实现的纯原生 Puerts JS 免费回退重置模组，原生接入 `PBZ Mods Menu`（自动跟随简/繁中文与英文），**0 个 UE4SS 原生 C++ Hook**，彻底避免与其他 UE4SS 模组（如 `PbzMapTracker`）产生 Hook 冲突或 UI 崩溃。
- **主武器与影之武装免费回退**：
  - 任意强化等级回退至 Lv.1 均不消耗重铸符（背包无符也能直接回退），走游戏原生 `ResetWeaponToLevel` 全额返还全部材料与残渣。
  - 突破升级与 1.03 连续/满级强化均跳过重铸符消耗警告弹窗。
  - 回退长按按钮直接复用游戏原生免费样式（`fuCost = 0`），不显示符箓图标与数量。
- **饰品与药品免费回退**：
  - 在强化界面的饰品/药品标签页选中等级 > 0 的物品时，自动绑定原生回退快捷键（键盘 `T` / 手柄 `Y` / `△`）。
  - 弹出中英文自适应原生确认框，精确列出将返还的残渣与材料明细；确认后全额返还并实时刷新等级与红点状态。
  - 已佩戴的饰品自动安全执行「卸下 → 降级 → 重装」，确保 GAS 词条效果与新等级一致。
  - 支持在 `PBZ Mods Menu` 中实时开关各项功能，并可切换单次降 1 级或一键退回初始等级。
